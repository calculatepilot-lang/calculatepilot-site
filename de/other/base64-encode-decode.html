Das Base64-Alphabet

Base64 verwendet 64 druckbare Zeichen. Drei Bytes (24 Bit) werden zu vier Zeichen mit je 6 Bit. Ist die Eingabe kein Vielfaches von drei Bytes, füllt das Zeichen = die letzte Gruppe auf.

Formeln

So werden die Zahlen berechnet.

memory

Drei Bytes zu vier Zeichen

Die Bytes werden als Bitstrom gelesen und in 6-Bit-Gruppen zerlegt, die jeweils einem Zeichen des Alphabets zugeordnet werden.

24 Bit = 3 Bytes = 4 Zeichen
straighten

Ausgabelänge

Je 3 Eingabebytes ergeben 4 Zeichen, aufgerundet und mit Auffüllung ergänzt.

Länge = 4 × ceil(Bytes ÷ 3)
Overhead ≈ 33 %
tag

Auffüllung (Padding)

Ein übrig gebliebenes Byte ergibt ==, zwei übrig gebliebene Bytes ergeben =.

Bytes mod 3 = 1 → "==", = 2 → "=", = 0 → keine

So kodieren und dekodieren Sie Base64

  • Wählen Sie Kodieren oder Dekodieren.
  • Fügen Sie Ihren Text oder Hex-Bytes ein.
  • Legen Sie die Optionen für URL-sicher, Auffüllung und Zeilenumbruch fest.
  • Kopieren Sie die Ausgabe oder verwenden Sie sie als nächste Eingabe, um den Rundlauf zu prüfen.

Base64 ist eine Kodierung, keine Verschlüsselung. Jeder kann es dekodieren, verwenden Sie es daher nie, um Geheimnisse zu verbergen.

Häufig gestellte Fragen

Wofür wird Base64 verwendet?expand_more

Um Binärdaten durch reine Textsysteme zu übertragen, etwa bei E-Mail-Anhängen, Data-URIs, JSON-Tokens (JWT) und HTTP-Basic-Authentifizierungs-Headern.

Ist Base64 eine Verschlüsselung?expand_more

Nein. Es schreibt Bytes lediglich mit einem anderen Alphabet um. Jeder kann es dekodieren.

Warum endet die Ausgabe mit =?expand_more

Padding. Base64 arbeitet in Gruppen von 3 Bytes. Ist die Eingabe kein Vielfaches von 3, vervollständigen ein oder zwei =-Zeichen die letzte Gruppe.

Was ist URL-sicheres Base64?expand_more

Eine Variante, die - und _ statt + und / verwendet, damit sie in URLs und Dateinamen stehen kann. JWTs lassen außerdem das =-Padding weg.

Warum ist die Ausgabe größer?expand_more

Je 3 Bytes werden zu 4 Zeichen, also etwa 33 % größer, plus Zeilenumbrüche, wenn Sie Zeilen umbrechen.
