Was Sie hier berechnen

Sie zahlen einen Betrag auf ein Festgeld ein und lassen ihn über eine feste Laufzeit stehen. Der Rechner zeigt Endkapital und Zinsen, wenn der Satz jährlich kapitalisiert.

Eine vorzeitige Kündigung kürzt oft den Zins. Rechnen Sie mit der vollen Laufzeit, nicht mit einem Wunschtermin.

Monatliche Verzinsung modellieren Sie im Zinseszinsrechner. Einen Sparplan mit Rate finden Sie im Sparrechner. Zur Einordnung der Rendite nutzen Sie den Anlagerechner.
