    Entropy of a random password

    Each character is chosen uniformly from N symbols, so the number of possibilities is N raised to the length L.

    entropy = L × log₂(N) bits
    menu_book

    Entropy of a passphrase

    Each word is picked at random from a list of W words.

    entropy = words × log₂(W) bits
    list here: 776 words, 9.60 bits each
    timer

    Average time to guess

    An attacker searches half the possibilities on average.

    time = 2(entropy − 1) ÷ guesses per second

    Worked examples

    Illustrative figures, each checked by hand. The first is the default setup.

    20 characters, all types

    Upper, lower, digits and symbols, 26 symbols (the default is close to this).

    pool = 26 + 26 + 10 + 26 = 88 symbols
    entropy = 20 × log₂(88) = 129.2 bits

    6-word passphrase

    Words picked from the 776-word list.

    entropy = 6 × log₂(776) = 57.6 bits
    adding a number adds 3.3 bits

    6-digit PIN

    Digits only.

    entropy = 6 × log₂(10) = 19.9 bits
    only 1,000,000 possibilities, so it needs a lockout

    How to create a strong password

    • Choose random password, passphrase or PIN.
    • Length matters most. Use at least 16 characters, or 7 or more words.
    • Copy it straight into a password manager.
    • Use a different password for every account.

    Use a password manager and turn on two-factor authentication. Time-to-guess figures assume the attacker has the hashed password and a fast hash; a well-designed system slows guessing greatly.

    Frequently asked questions

    Is this generator safe to use?expand_more

    Passwords are created in your browser with the secure random generator. Nothing is sent to a server or stored.

    How long should a password be?expand_more

    At least 16 characters for a random password, and longer for important accounts. NIST guidance stresses length over complexity rules.

    What is entropy?expand_more

    A measure of unpredictability in bits. Each extra bit doubles the number of guesses needed. Above about 80 bits is very hard to brute force.

    Are passphrases as good as passwords?expand_more

    A passphrase of enough random words is strong and easier to remember. Six words from this list is about 58 bits; seven or eight is stronger.

    Should I avoid similar-looking characters?expand_more

    It only matters if you type the password by hand. It slightly reduces the pool, so add a couple of characters to compensate.
