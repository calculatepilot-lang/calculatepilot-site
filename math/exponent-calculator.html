    What is an exponent?

    An exponent says how many times to use a base as a factor: b³ = b × b × b. It extends to zero (b⁰ = 1), negative numbers (b⁻ⁿ = 1 ÷ bⁿ) and fractions (b^(1/n) is the nth root of b). Real exponents are defined through the exponential function: bˣ = eˣ ˡⁿ ᵇ for b > 0.

    Scientific notation

    A number is in scientific notation when written a × 10ⁿ with 1 ≤ |a| < 10. Engineering notation restricts n to multiples of 3 so it lines up with SI prefixes (kilo, mega, milli…). E-notation such as 6.02e23 means 6.02 × 10²³.

    Frequently asked questions

    How is a fractional power like 4^2.5 calculated?expand_more

    Write the exponent as a fraction, 2.5 = 5/2. The denominator is the root and the numerator the power: 4^(5/2) = (√4)⁵ = 2⁵ = 32. The calculator detects such fractions automatically and shows the exact value when it exists.

    What happens with a negative base and a fractional exponent?expand_more

    If the exponent is a fraction with an odd denominator the result is real ((−8)^(1/3) = −2). With an even denominator, such as (−4)^(1/2), there is no real result; the principal complex value is 0 + 2i, which this page reports when it applies.

    Why is 0⁰ undefined?expand_more

    Two rules conflict: x⁰ = 1 for every non-zero x, but 0ˣ = 0 for every positive x. Neither wins, so 0⁰ is left indeterminate in analysis. Many programming languages and combinatorics texts define it as 1 by convention; this calculator reports it as indeterminate.

    What precision limits apply to large results?expand_more

    Whole-number powers of whole numbers are exact big integers. Other results use IEEE 754 double precision: about 15–17 significant digits, with overflow to ∞ above about 1.8 × 10³⁰⁸ and underflow to 0 below about 5 × 10⁻³²⁴.

    What is the difference between exponential growth and a power function?expand_more

    In a power function like x², the base varies and the exponent is fixed. In an exponential function like 2ˣ the base is fixed and the exponent varies — so it eventually outgrows every power function.

    How do I find the doubling time?expand_more

    For continuous growth N = N₀eᵏᵗ, the doubling time is ln 2 ÷ k. At k = 0.05 per year that is 0.693147 ÷ 0.05 ≈ 13.86 years. For decay, the half-life is ln 2 ÷ |k|.
