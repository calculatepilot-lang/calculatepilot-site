    Three kinds of average

    Each mean answers a different question. Pick the one that matches how your numbers combine.

    add

    Arithmetic mean

    x̄ = Σxᵢ ÷ n

    The everyday average. Best for values that add up — heights, marks, weights — but pulled by extreme values.

    close

    Geometric mean

    G = (x₁ · x₂ · … · xₙ)^(1/n)

    For quantities that multiply — growth factors, index ratios. Requires every value to be above zero.

    functions

    Harmonic mean

    H = n ÷ Σ(1 ÷ xᵢ)

    For averaging rates over equal amounts — such as speed over equal distances. Requires every value to be above zero.

    Skewness: how mean, median and mode compare

    When a distribution is lopsided, the three measures separate in a predictable way (though the ordering is a guide, not a law).

    Symmetric

    Mean ≈ median ≈ mode. The centre of mass sits at the peak, as in a bell-shaped distribution.

    Right-skewed (positive)

    Mean > median > mode is typical. A long tail of high values, such as incomes or house prices, drags the mean upward.

    Left-skewed (negative)

    Mean < median < mode is typical. A tail of low values, such as age at death in high-income countries or scores on an easy exam, pulls the mean down.

    Which average should you report?

    The right choice depends on the scale of measurement and how skewed the data is.

    Type of dataSensitivity to outliersBest measureExample
    Nominal (categories)Not applicable — no numeric orderMode onlyMost common shoe size or party choice

    Interval / ratio, skewedHigh for the meanMedian (or trimmed mean)House prices, salaries, response times

    Worked example: a skewed set of household incomes

    Twelve household incomes in thousands of dollars: 38, 42, 45, 48, 52, 55, 58, 62, 65, 70, 95, 650. (Load "Skewed incomes" from the examples menu to see it above.)

    Mean distorted

    Σx = 1,280 ÷ 12
    mean = 106.67 ($106.7k)

    11 of 12 households (91.7%) earn less than this “average”, because one very large value inflates it.

    Median robust

    6th and 7th values: 55 and 58
    median = (55 + 58) ÷ 2 = 56.5

    Half of households earn less and half more, so the median describes a typical household far better here.

    What are the mean, median and mode?

    The mean is the sum of the values divided by how many there are. The median is the middle value once the list is sorted — or the mean of the two middle values when there is an even number of them. The mode is the value that occurs most often; a data set can have one mode, several, or none.

    How to calculate them

    • Mean: add all values, then divide by the count.
    • Median: sort the values. With n values, take the value at position (n + 1) ÷ 2, averaging the two middle values when n is even.
    • Mode: count each value; the highest count wins. If every value occurs once there is no mode.
    • Trimmed mean: drop the lowest and highest 10% of values (rounded down), then average the rest.

    Frequently asked questions

    What if a data set has more than one mode?expand_more

    Then it is bimodal (two modes) or multimodal (more). This calculator lists every value that ties for the highest frequency. If every value appears exactly once, there is no mode.

    Why does an extreme value change the mean but not the median?expand_more

    The mean uses every value's size, so one very large number pulls it up. The median depends only on the middle position in the sorted list, so making the largest value larger changes nothing.

    What is the difference between arithmetic, geometric and harmonic means?expand_more

    Arithmetic averages values that add, geometric averages values that multiply (such as growth factors), and harmonic averages rates over equal amounts. For positive, unequal values they always satisfy harmonic ≤ geometric ≤ arithmetic.

    How do I find the median with an even number of values?expand_more

    Sort the list and average the two middle values. For 2, 4, 6, 8 the middle values are 4 and 6, so the median is 5.

    How does the value:frequency format work?expand_more

    Type each distinct value followed by a colon and how many times it occurs, for example 5:2, 8:4 means two 5s and four 8s. The calculator expands it into a full list before working everything out.

    What is a trimmed mean?expand_more

    A trimmed mean discards a fixed share of the smallest and largest values before averaging. Here 10% is removed from each end, rounded down, so it resists outliers while still using most of the data.
