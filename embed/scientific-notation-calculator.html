    The three notations

    • Standard scientific: m × 10ⁿ with exactly one non-zero digit before the decimal point (1 ≤ |m| < 10).
    • Engineering notation: the exponent is forced to a multiple of 3, so the mantissa is 1 ≤ |m| < 1000 — this aligns directly with SI prefixes (kilo, mega, milli, …).
    • E-notation: the plain-text computing form, m followed by "e" and the exponent, e.g. 4.582e-5 — identical in value to standard scientific notation.

    Frequently asked questions

    What's the difference between scientific and engineering notation?expand_more

    Standard scientific notation always has exactly one digit before the decimal point. Engineering notation instead forces the exponent to a multiple of 3, so the mantissa can have 1, 2 or 3 digits before the point — this matches SI prefixes like kilo (10³) and mega (10⁶) directly.

    Why do calculators and programs write "e" instead of "× 10"?expand_more

    "e" notation (like 4.582e-5) is a plain-text way to write scientific notation without special symbols, used across programming languages, spreadsheets and calculator displays — mathematically it means exactly the same as 4.582 × 10⁻⁵.

    How does multiplying in scientific notation work?expand_more

    Multiply the mantissas and add the exponents: (a×10ᵐ)×(b×10ⁿ) = (a×b)×10ᵐ⁺ⁿ. If the mantissa product is 10 or more (or less than 1), renormalize by shifting the decimal point and adjusting the exponent.

    Why use scientific notation at all?expand_more

    It makes very large or very small numbers compact and easy to compare — and it separates the number's precision (the mantissa's significant figures) from its scale (the exponent), which is why it's the standard in science and engineering.

    How is rounding handled when converting?expand_more

    Using exact half-to-even (banker's) rounding on the digit string itself — not on a floating-point approximation — so results match the textbook rule precisely, including for ties.
