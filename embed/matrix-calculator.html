    Determinant & inverse

    For A = [[3, 2], [1, 4]], find det(A) and A⁻¹.

    det(A) = 3·4 − 2·1 = 10
    A⁻¹ = (1/10)[[4, −2], [−1, 3]]
    = [[0.4, −0.2], [−0.1, 0.3]]

    Eigenvalues

    Find the eigenvalues of the same matrix A.

    tr(A) = 7, det(A) = 10
    λ² − 7λ + 10 = 0 → (λ − 5)(λ − 2) = 0
    λ₁ = 5, λ₂ = 2

    Cramer's rule

    Solve Ax = b for b = (8, 7) with the same A.

    x₁ = det([[8,2],[7,4]]) / det(A) = 18/10 = 1.8
    x₂ = det([[3,8],[1,7]]) / det(A) = 13/10 = 1.3
    x = (1.8, 1.3)

    Key 2×2 formulas

    • Determinant: det(A) = a·d − b·c for A = [[a, b], [c, d]].
    • Inverse: A⁻¹ = (1/det A)·[[d, −b], [−c, a]], defined only when det(A) ≠ 0.
    • Trace: tr(A) = a + d, the sum of the diagonal entries.
    • Characteristic polynomial: p(λ) = λ² − tr(A)λ + det(A); its roots are the eigenvalues.
    • Cramer's rule: for Ax = b, xᵢ = det(Aᵢ) / det(A), where Aᵢ replaces column i of A with b.

    Frequently asked questions

    What does det(A) = 0 mean?expand_more

    The rows (or columns) of A are linearly dependent — one is a scalar multiple of the other. The matrix has no inverse, and it maps the plane onto a line or a single point rather than a full 2D region.

    How do I check that an inverse is correct?expand_more

    Multiply A by the computed A⁻¹: the result should be the identity matrix I = [[1, 0], [0, 1]], up to rounding. This calculator performs that check for you.

    Can a 2×2 matrix have complex eigenvalues?expand_more

    Yes — whenever the discriminant tr(A)² − 4·det(A) is negative, such as for a rotation matrix (with angle not a multiple of 180°). The eigenvalues then form a complex conjugate pair.

    Why does Cramer's rule fail when det(A) = 0?expand_more

    Because it divides by det(A). A singular system either has no solution or infinitely many, and Cramer's rule cannot distinguish those cases — use row reduction instead.

    What do the eigenvalues tell you geometrically?expand_more

    Along each eigenvector direction, A acts as pure scaling by the corresponding eigenvalue — no rotation. Real eigenvalues mean the map stretches or flips along fixed directions; complex ones mean the map includes rotation.

    Is A⁻¹A always equal to AA⁻¹?expand_more

    Yes, for a square invertible matrix, A⁻¹A = AA⁻¹ = I. This is a special property of square matrices; it does not hold for non-square matrices, which only have one-sided inverses at best.
