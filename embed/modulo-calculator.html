    Key definitions

    • Modulo: a mod n is the remainder left after dividing a by n, with 0 ≤ (a mod n) < n for n > 0 under the floored convention.
    • Congruence: a ≡ b (mod n) means n divides (a − b) exactly — a and b leave the same remainder.
    • Modular inverse: a⁻¹ mod n is the value x with a·x ≡ 1 (mod n); it exists exactly when gcd(a, n) = 1.
    • Modular exponentiation: aᵇ mod n, computed by repeated squaring so it stays fast even for huge b.

    Frequently asked questions

    Why is −7 mod 3 equal to 2, not −1?expand_more

    Under the mathematical (floored) convention, the result of a mod n always has the same sign as n (here positive), so it stays in [0, n). −7 = 3 × (−3) + 2, giving remainder 2. Some programming languages instead truncate toward zero, giving −1 — this calculator shows both.

    When does a modular inverse not exist?expand_more

    Exactly when gcd(a, n) ≠ 1 — that is, a and n share a common factor. For example, 4 has no inverse mod 8, since gcd(4, 8) = 4.

    How is aᵇ mod n computed for a huge exponent b?expand_more

    By fast (binary) exponentiation: repeatedly squaring a mod n and multiplying in the factors corresponding to the binary digits of b, taking the modulus at every step. This needs only about log₂(b) multiplications, so even a 1000-digit exponent computes instantly.

    What is the modulo operation used for?expand_more

    Clock and calendar arithmetic, hash tables, checksums, cryptography (RSA relies on modular exponentiation), pseudo-random number generators, and cycling through array indices.

    Is a mod 0 defined?expand_more

    No — division by zero is undefined, so a mod 0 has no value. This calculator flags it as an error rather than returning a result.

    How is congruence different from equality?expand_more

    Equality means two numbers are identical. Congruence mod n is weaker: it only requires them to leave the same remainder when divided by n, so infinitely many numbers (…, b−n, b, b+n, b+2n, …) are all congruent to b.
