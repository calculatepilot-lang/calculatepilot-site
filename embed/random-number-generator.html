    How each mode generates numbers

    • Integer / Float: uses crypto.getRandomValues, the same cryptographically secure source browsers use for security tokens — far higher quality than Math.random().
    • Gaussian: combines two uniform CSPRNG draws with the Box–Muller transform to produce normally-distributed values with your chosen mean and standard deviation.
    • Seeded: uses the mulberry32 deterministic algorithm — the same seed always produces the same sequence, useful for reproducible tests and simulations (not for security).

    Frequently asked questions

    Is this suitable for cryptographic keys?expand_more

    The Integer and Float modes draw from crypto.getRandomValues, the browser's cryptographically secure generator, so the raw randomness is suitable. For actual key material, use a dedicated cryptography library that handles encoding and key formats correctly — this tool is for general-purpose random numbers.

    What does "no duplicates" mean?expand_more

    It samples without replacement — like drawing lottery balls without putting them back — so every value in the output is distinct. It requires the range to contain at least as many values as you're requesting.

    Why use a seeded generator instead of true randomness?expand_more

    A seeded (deterministic) generator lets you reproduce the exact same "random" sequence again later — essential for debugging simulations, sharing reproducible examples, or writing tests with predictable output.

    How does the Box–Muller transform create a normal distribution?expand_more

    It takes two independent uniform random numbers and applies √(−2 ln u₁)·cos(2πu₂) (and a sine variant), which can be shown mathematically to produce exactly standard normal N(0,1) values — then scaled by σ and shifted by μ.

    Why is Math.random() not used here?expand_more

    Math.random() is not specified to be cryptographically secure and its algorithm varies by browser. crypto.getRandomValues() is a web standard specifically designed for unpredictable, high-quality randomness.
