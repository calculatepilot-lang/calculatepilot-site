El alfabeto Base64

Base64 usa 64 caracteres imprimibles. Tres bytes (24 bits) se convierten en cuatro caracteres de 6 bits cada uno. Si la entrada no es múltiplo de tres bytes, el relleno = completa el último grupo.

Fórmulas

Cómo se calculan los números.

memory

Tres bytes a cuatro caracteres

Los bytes se leen como un flujo de bits y se cortan en grupos de 6 bits, cada uno asignado a un carácter del alfabeto.

24 bits = 3 bytes = 4 caracteres
straighten

Longitud de salida

Cada 3 bytes de entrada dan 4 caracteres, redondeando hacia arriba, con relleno para completar.

longitud = 4 × ceil(bytes ÷ 3)
sobrecarga ≈ 33%
tag

Relleno

Un byte sobrante añade ==, dos bytes sobrantes añaden =.

bytes mod 3 = 1 → "==", = 2 → "=", = 0 → ninguno

Cómo codificar y decodificar Base64

  • Elige Codificar o Decodificar.
  • Pega tu texto o bytes en hexadecimal.
  • Configura las opciones de seguro para URL, relleno y ajuste de línea.
  • Copia la salida o úsala como siguiente entrada para comprobar el viaje de ida y vuelta.

Base64 es una codificación, no un cifrado. Cualquiera puede decodificarlo, así que nunca lo uses para ocultar secretos.

Preguntas frecuentes

¿Para qué se usa Base64?expand_more

Para transportar datos binarios a través de sistemas que solo admiten texto, como archivos adjuntos de correo, URI de datos, tokens JSON (JWT) y encabezados de autenticación básica HTTP.

¿Es Base64 un cifrado?expand_more

No. Solo reescribe los bytes con un alfabeto distinto. Cualquiera puede decodificarlo.

¿Por qué la salida termina en =?expand_more

Relleno. Base64 trabaja en grupos de 3 bytes. Cuando la entrada no es múltiplo de 3, uno o dos caracteres = completan el último grupo.

¿Qué es Base64 seguro para URL?expand_more

Una variante que usa - y _ en lugar de + y /, para poder incluirse en URL y nombres de archivo. Los JWT también omiten el relleno =.

¿Por qué la salida es más grande?expand_more

Cada 3 bytes se convierten en 4 caracteres, aproximadamente un 33% más grande, además de los saltos de línea si ajustas las líneas.
