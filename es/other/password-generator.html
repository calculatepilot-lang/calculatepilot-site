    Entropía de una contraseña aleatoria

    Cada carácter se elige de forma uniforme entre N símbolos, de modo que el número de posibilidades es N elevado a la longitud L.

    entropía = L × log₂(N) bits
    menu_book

    Entropía de una frase de contraseña

    Cada palabra se elige al azar de una lista de W palabras.

    entropía = palabras × log₂(W) bits
    lista aquí: 776 palabras, 9.60 bits cada una
    timer

    Tiempo medio para adivinarla

    Un atacante recorre, de media, la mitad de las posibilidades.

    tiempo = 2(entropía − 1) ÷ intentos por segundo

    Palabras elegidas de la lista de 776 palabras.

    añadir un número suma 3.3 bits

    PIN de 6 dígitos

    Solo dígitos.

    entropía = 6 × log₂(10) = 19.9 bits
    solo 1,000,000 de posibilidades, por lo que necesita un bloqueo tras varios intentos

    Cómo crear una contraseña segura

    • Elige contraseña aleatoria, frase de contraseña o PIN.
    • Lo más importante es la longitud. Usa al menos 16 caracteres, o 7 palabras o más.
    • Cópiala directamente en un gestor de contraseñas.
    • Usa una contraseña distinta para cada cuenta.

    Usa un gestor de contraseñas y activa la autenticación en dos pasos. Las cifras de tiempo para adivinarla suponen que el atacante tiene la contraseña con hash y un hash rápido; un sistema bien diseñado ralentiza mucho los intentos.

    Preguntas frecuentes

    ¿Es seguro usar este generador?expand_more

    Las contraseñas se crean en tu navegador con el generador aleatorio seguro. No se envía nada a un servidor ni se guarda.

    ¿Qué longitud debe tener una contraseña?expand_more

    Al menos 16 caracteres para una contraseña aleatoria, y más para las cuentas importantes. Las directrices del NIST dan prioridad a la longitud sobre las reglas de complejidad.

    ¿Qué es la entropía?expand_more

    Una medida de la imprevisibilidad en bits. Cada bit adicional duplica el número de intentos necesarios. Por encima de unos 80 bits es muy difícil de descifrar por fuerza bruta.

    ¿Son las frases de contraseña tan buenas como las contraseñas?expand_more

    Una frase de contraseña con suficientes palabras aleatorias es segura y más fácil de recordar. Seis palabras de esta lista equivalen a unos 58 bits; siete u ocho son más seguras.

    ¿Debo evitar los caracteres de aspecto similar?expand_more

    Solo importa si escribes la contraseña a mano. Reduce ligeramente el conjunto de caracteres, así que añade un par de caracteres para compensarlo.
