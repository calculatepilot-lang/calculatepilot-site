Simulador de dados y calculadora de probabilidad

Lanza cualquier expresión de dados, como 4d6kh3+2, consulta cada dado y obtén la probabilidad exacta de cada total. Admite reglas de conservar y descartar, modificadores, dados explosivos y una simulación de 10.000 tiradas.

Fórmulas

Cómo se calculan los números.

functions

Media y varianza

Para un dado de s caras, y luego sumado para n dados.

media = n × (s + 1) ÷ 2
varianza = n × (s² − 1) ÷ 12
bar_chart

Probabilidad exacta de un total

Se calcula combinando los dados de uno en uno. Con reglas de conservar o descartar, se cuentan todas las combinaciones cuando son pocas; si no, el gráfico se simula.

P(total = k) = maneras de obtener k ÷ sn
shuffle

Tiradas aleatorias justas

Las tiradas usan el generador aleatorio seguro del navegador. Los valores que sesgarían el resultado se descartan y se vuelven a generar.

tirada = (aleatorio mod s) + 1, se vuelve a generar si cae en la cola sesgada

Ejemplos resueltos

Cifras ilustrativas, cada una comprobada a mano. La primera es la configuración predeterminada.

Puntuación de característica

4d6, descartando el más bajo (4d6kh3), más 2 (el valor predeterminado).

media de 4d6kh3 = 12,24, así que con +2 la media es 14,24
rango de 3 a 18 antes del modificador, de 5 a 20 después

Ventaja

Lanza dos d20 y conserva el más alto.

media de 2d20kh1 = 13,825 frente a 10,50 de un solo d20
P(20) = 1 − (19/20)² = 9,75 %

Bola de fuego

8d6.

media = 8 × 3,5 = 28
desv. est. = √(8 × 35 ÷ 12) = 4,83

Cómo usar el simulador de dados

  • Escribe una expresión como 2d6+3, o toca los dados y los ajustes preestablecidos para crear una.
  • Lanza los dados. Los dados descartados se muestran tachados.
  • Consulta el valor esperado, la probabilidad de este resultado y el gráfico de probabilidad.
  • Ejecuta 10.000 tiradas para comparar la simulación con las probabilidades exactas.

Las tiradas son aleatorias. Los resultados pasados no cambian las probabilidades futuras.

Preguntas frecuentes

¿Qué significa 4d6kh3?expand_more

Lanza cuatro dados de seis caras y conserva los tres más altos. Es una forma habitual de generar las puntuaciones de característica de un personaje, con un promedio de unos 12,24.

¿Qué son la ventaja y la desventaja?expand_more

La ventaja consiste en lanzar dos d20 y quedarse con el más alto (2d20kh1). La desventaja se queda con el más bajo (2d20kl1).

¿Las tiradas son realmente aleatorias?expand_more

Provienen de la fuente aleatoria criptográfica del navegador, adecuada para juegos. Se descartan los valores que causarían sesgo de módulo.

¿Qué son los dados explosivos?expand_more

Cuando un dado muestra su número más alto, lo vuelves a lanzar y sumas el resultado, repitiendo mientras siga mostrando el máximo.

¿Por qué las sumas se concentran en el centro?expand_more

Hay más maneras de obtener los totales intermedios. Con 2d6, el siete se puede obtener de seis maneras, mientras que el dos solo de una.
