Cómo funciona

Las aportaciones periódicas pueden crecer con el interés compuesto. Los rendimientos obtenidos también pueden generar nuevos rendimientos.

Importancia del plazo

Un plazo más largo o una rentabilidad mayor puede aumentar el valor final, pero el rendimiento real nunca está garantizado.

Preguntas frecuentes

¿Cuándo se realizan las aportaciones?

El cálculo supone que se realizan al final de cada mes.

¿El resultado está garantizado?

No. La rentabilidad introducida es una hipótesis para realizar la proyección.
