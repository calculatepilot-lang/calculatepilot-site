    Error porcentual

    Úsalo cuando compares una medición con un valor aceptado conocido. El valor aceptado es el denominador, así que la respuesta indica cuánto te desviaste respecto a la verdad.

    |medido − aceptado| ÷ |aceptado| × 100
    functions

    Diferencia porcentual

    Úsala al comparar dos mediciones cuando ninguna es una referencia. El promedio de los dos valores es el denominador, por lo que el orden no importa.

    |A − B| ÷ ((A + B) ÷ 2) × 100
    ssid_chart

    Error frente a incertidumbre

    El error es la diferencia respecto al valor verdadero, que normalmente se desconoce. La incertidumbre describe la duda sobre una medición. Un error porcentual menor que tu incertidumbre es coherente con el valor aceptado.

    desviación sistemática + dispersión aleatoria

    Ejemplos resueltos

    Mediciones ilustrativas, cada una comprobada a mano. Usa los ajustes rápidos de arriba para reproducir la primera, la tercera y la cuarta.

    Medición de la gravedad con un péndulo

    Un estudiante mide g = 9.62 m/s²; el valor estándar es 9.80665 m/s².

    |9.62 − 9.80665| = 0.18665
    0.18665 ÷ 9.80665 = 0.019033
    error porcentual = 1.9033 % (por debajo)

    Molaridad de titulación

    Una solución preparada a 0.1000 M mide 0.1008 M.

    |0.1008 − 0.1000| = 0.0008
    0.0008 ÷ 0.1000 = 0.008
    error porcentual = 0.8000 % (por encima)

    Eje mecanizado

    Un eje de 50.000 mm mide 50.042 mm frente a una tolerancia de ±0.050 mm.

    |50.042 − 50.000| = 0.042 mm
    0.042 ÷ 50 = 0.00084
    error porcentual = 0.084 %
    0.042 ≤ 0.050 → dentro de la tolerancia

    ¿Qué es el error porcentual?

    El error porcentual expresa cuánto se aleja un valor medido (experimental) de un valor aceptado (teórico), como porcentaje del valor aceptado. Un error porcentual pequeño significa que la medición está cerca de la referencia. Es habitual en laboratorios de física, química e ingeniería.

    Cómo calcular el error porcentual

    • Resta: medido − aceptado. Este es el error con signo.
    • Toma el valor absoluto para obtener el error absoluto, |Δ|.
    • Divide entre el valor absoluto del valor aceptado para obtener el error relativo.
    • Multiplica por 100 para obtener el error porcentual.

    Algunos cursos conservan el signo (negativo = medido por debajo, positivo = medido por encima) y otros usan el valor absoluto; esta página muestra ambos.

    Preguntas frecuentes

    ¿Puede el error porcentual ser negativo?expand_more

    Según la definición estricta de los manuales, el error porcentual es el valor absoluto y, por tanto, nunca es negativo. Muchos laboratorios conservan el signo para indicar la dirección: negativo significa que tu medición está por debajo del valor aceptado y positivo, por encima. Cambia el ajuste de Signo para elegir.

    ¿Qué error porcentual es aceptable?expand_more

    Depende del campo y del propósito. Un laboratorio docente puede aceptar unos pocos puntos porcentuales, mientras que la fabricación de precisión o la química analítica pueden exigir mucho menos del 1 %. Usa la comprobación de tolerancia con el límite que fije tu curso, norma o especificación.

    ¿Qué pasa si el valor teórico es cero?expand_more

    El error porcentual no está definido porque se divide entre el valor aceptado. Indica en su lugar el error absoluto con sus unidades, o usa una tolerancia absoluta en la comprobación de tolerancia.

    ¿Cómo se aplican las cifras significativas?expand_more

    Redondea solo la respuesta final, no los pasos intermedios. El ajuste de cifras significativas redondea los resultados mostrados; el cálculo en sí siempre usa la precisión completa.

    ¿Cuál es la diferencia entre error porcentual y diferencia porcentual?expand_more

    El error porcentual compara una medición con un valor de referencia aceptado y divide entre ese valor. La diferencia porcentual compara dos mediciones cuando ninguna es una referencia y divide entre su promedio.

    ¿Por qué el error porcentual no es lo mismo que la incertidumbre?expand_more

    El error porcentual requiere un valor aceptado conocido, mientras que la incertidumbre describe la duda en la propia medición. Un error porcentual menor que la incertidumbre de la medición significa que el resultado concuerda con el valor aceptado dentro de lo que la medición puede resolver.
