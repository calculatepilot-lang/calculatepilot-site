    ¿Qué es un exponente?

    Un exponente indica cuántas veces se usa una base como factor: b³ = b × b × b. Se extiende al cero (b⁰ = 1), a los números negativos (b⁻ⁿ = 1 ÷ bⁿ) y a las fracciones (b^(1/n) es la raíz n-ésima de b). Los exponentes reales se definen mediante la función exponencial: bˣ = eˣ ˡⁿ ᵇ para b > 0.

    Notación científica

    Un número está en notación científica cuando se escribe a × 10ⁿ con 1 ≤ |a| < 10. La notación ingenieril restringe n a múltiplos de 3 para que coincida con los prefijos del SI (kilo, mega, mili…). La notación E, como 6.02e23, significa 6.02 × 10²³.

    Preguntas frecuentes

    ¿Cómo se calcula una potencia fraccionaria como 4^2.5?expand_more

    Escribe el exponente como fracción, 2.5 = 5/2. El denominador es la raíz y el numerador la potencia: 4^(5/2) = (√4)⁵ = 2⁵ = 32. La calculadora detecta estas fracciones automáticamente y muestra el valor exacto cuando existe.

    ¿Qué ocurre con una base negativa y un exponente fraccionario?expand_more

    Si el exponente es una fracción con denominador impar, el resultado es real ((−8)^(1/3) = −2). Con denominador par, como (−4)^(1/2), no hay resultado real; el valor complejo principal es 0 + 2i, que esta página indica cuando corresponde.

    ¿Por qué 0⁰ no está definido?expand_more

    Dos reglas entran en conflicto: x⁰ = 1 para todo x distinto de cero, pero 0ˣ = 0 para todo x positivo. Ninguna prevalece, así que 0⁰ queda indeterminado en el análisis. Muchos lenguajes de programación y textos de combinatoria lo definen como 1 por convención; esta calculadora lo muestra como indeterminado.

    ¿Qué límites de precisión se aplican a los resultados grandes?expand_more

    Las potencias enteras de números enteros son enteros grandes exactos. Los demás resultados usan doble precisión IEEE 754: unas 15–17 cifras significativas, con desbordamiento a ∞ por encima de aproximadamente 1.8 × 10³⁰⁸ y subdesbordamiento a 0 por debajo de aproximadamente 5 × 10⁻³²⁴.

    ¿Cuál es la diferencia entre el crecimiento exponencial y una función potencia?expand_more

    En una función potencia como x², la base varía y el exponente es fijo. En una función exponencial como 2ˣ la base es fija y el exponente varía, por lo que con el tiempo supera a cualquier función potencia.

    ¿Cómo calculo el tiempo de duplicación?expand_more

    Para un crecimiento continuo N = N₀eᵏᵗ, el tiempo de duplicación es ln 2 ÷ k. Con k = 0.05 por año son 0.693147 ÷ 0.05 ≈ 13.86 años. Para el decaimiento, la vida media es ln 2 ÷ |k|.
