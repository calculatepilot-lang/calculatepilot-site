How to Use a Basic Calculator: Keys, Memory and Common Mistakes

Every key on a basic calculator explained, with worked examples you can try.

→ Use the free Basic Calculator

Short answer: A basic calculator evaluates strictly left to right: 2 + 3 × 4 gives 20, not 14. Use C to clear the entry, AC to clear everything, % to divide by 100, and M+ / MR to store and recall a subtotal.

The basic flow

  1. Type the first number.
  2. Press an operator: +, −, × or ÷.
  3. Type the second number.
  4. Press = (or another operator to keep chaining).

Left to right, not PEMDAS

Each operator is applied as soon as you press the next one. Entering 2 + 3 × 4 = gives 20 because 2 + 3 is worked out first. To get 14, calculate 3 × 4 first (12) and then add 2. More in left to right vs PEMDAS.

Common mistakes

  • Pressing = between steps and losing a running total.
  • Using % as if it meant “percent of”. It only divides by 100, so 80 × 15 % = is how you find 15% of 80 (12).
  • Expecting brackets. A basic calculator has none.

Frequently asked questions

What is a basic calculator?

A calculator for everyday arithmetic: add, subtract, multiply, divide, percent, square root and memory, without brackets or functions.

What is the difference between C and AC?

C clears only the number you are typing. AC clears the whole calculation.

Why does a basic calculator give 20 for 2 + 3 × 4?

It applies each operator immediately, left to right. A scientific calculator follows PEMDAS and gives 14.

Can I use the keyboard?

Yes: digits, + - * /, Enter or =, % and Esc for all clear.
