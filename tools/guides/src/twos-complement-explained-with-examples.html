Two's Complement Explained: Negative Binary Numbers With Examples

How computers store negative integers, with 8-bit examples and the signed ranges for 8 to 64 bits.

→ Use the free Binary Calculator

Short answer: To get the two's complement of a number, flip every bit and add 1. In 8 bits, −5 is 11111011. The top bit is the sign, and an 8-bit signed value ranges from −128 to 127.

The rule

  1. Write the positive number in binary: 5 = 00000101.
  2. Flip every bit: 11111010.
  3. Add 1: 11111011. That is −5.

Reading a negative value

If the top bit is 1, flip all bits and add 1 to get the magnitude. 11111011 flips to 00000100, plus 1 is 00000101 = 5, so the value is −5.

Subtraction by addition

7 − 5 becomes 7 + (−5): 00000111 + 11111011 = 1 00000010. Drop the carry out of the top bit and you have 00000010, which is 2.

Why it is used

The same adder circuit handles signed and unsigned values, and there is only one zero. Enter any value in the two's complement mode of the Binary Calculator to see each step. Related: binary conversion chart.

Frequently asked questions

How do you find two's complement?

Flip every bit, then add 1.

What is -5 in 8-bit binary?

11111011.

What is the range of an 8-bit signed number?

-128 to 127.

Why is there only one zero in two's complement?

Flipping 00000000 and adding 1 returns 00000000, so negative zero does not exist.
