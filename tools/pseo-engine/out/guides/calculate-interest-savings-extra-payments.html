Calculate Interest Savings Extra Payments: a worked example with the formula shown step by step, a scenario table and the assumptions behind it.

Quick answer

With these example inputs (starting balance $700; monthly deposit $200; interest rate 6%; years 3 years), the balance at the end comes to $8,704.90.

Worked example

These steps use the formula behind the Savings Calculator, with the example inputs above.

  1. Start with $700 and add $200 each month for 3 years at 6% a year, compounded monthly.
  2. Balance = start x (1 + r)^n + deposit x ((1 + r)^n - 1) / r, with r = rate / 12 and n = months.
  3. Balance = $8,704.90: $7,900 deposited plus $804.90 interest.
