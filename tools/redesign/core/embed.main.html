Technical Embed Standards

What webmasters and publishers should know before embedding.

speed 100% Client-Side

Each embed is a lightweight iframe. Calculations run in the visitor’s browser with no API calls.

security Sandboxed Security

Embeds load over HTTPS inside a standard iframe, which keeps them separate from your page’s own scripts and styles.

link Attribution

The free plan keeps a visible “Powered by CalculatePilot” link back to the calculator. The Pro license removes it.
