Permutation vs combination: does order matter?

A permutation counts each different ordering separately. A combination treats orderings of the same items as one selection, so every combination corresponds to r! permutations.

Permutations order matters

Three tokens A, B, C can be arranged in 3! = 6 different orders:

ABC · ACB · BAC · BCA · CAB · CBA

Each ordered arrangement is a separate outcome — like the gold, silver and bronze places in a race.

Combinations order does not matter

All six orders contain the same three tokens, so they collapse into a single combination:

{ A, B, C } — 1 combination

C(n, r) = P(n, r) ÷ r! — like choosing a committee, where only membership counts.

    The four counting formulas

    Combinations no repetition

    C(n, r) = n! ÷ (r!(n − r)!)

    Unordered selections where each element can be picked at most once.

    Permutations no repetition

    P(n, r) = n! ÷ (n − r)!

    Ordered arrangements without reuse: n choices, then n − 1, and so on.

    Combinations with repetition

    C(n + r − 1, r)

    Multisets of size r from n types (the “stars and bars” count), where items may repeat and order is ignored.

    Permutations with repetition

    nʳ

    Ordered sequences where each of the r positions can independently be any of the n symbols.

    What are permutations and combinations?

    Permutations and combinations count the ways to select items from a set. A permutation is an ordered arrangement; a combination is an unordered selection. The factorial n! = n × (n − 1) × … × 1 underlies both, with 0! defined as 1.

    How to choose the formula

    • Does the order of the chosen items create a different outcome? If yes, use permutations; if no, use combinations.
    • Can the same item be chosen more than once? If yes, use the “with repetition” formulas.

    Frequently asked questions

    What is the difference between a permutation and a combination?expand_more

    A permutation counts ordered arrangements, so (1, 2, 3) and (3, 2, 1) are different. A combination counts unordered selections, so they are the same. Because each combination of size r can be arranged in r! ways, the number of permutations is always r! times the number of combinations.

    Why is a “combination lock” really a permutation lock?expand_more

    Because the order in which you enter the digits matters: 1-2-3 opens it but 3-2-1 does not. Strictly it is a count of ordered sequences, so it uses permutation formulas (with repetition if digits can be reused).

    How does this calculator handle very large factorials?expand_more

    It uses arbitrary-precision integer arithmetic, so results are exact rather than rounded to floating-point. Numbers with more than 18 digits are shown in scientific notation, and “Copy exact value” copies every digit.

    What are “stars and bars”?expand_more

    It is a method for counting combinations with repetition. Choosing r items from n types, with repeats allowed and order ignored, is equivalent to placing r stars and n − 1 bars in a row, which gives C(n + r − 1, r).

    What is 0! and what if r = 0?expand_more

    By definition 0! = 1. Choosing zero items can be done in exactly one way, so C(n, 0) = P(n, 0) = 1, and n⁰ = 1.

    Why can r not exceed n without repetition?expand_more

    You cannot pick more distinct items than exist, so the count is 0. The calculator asks you to enter r ≤ n for the no-repetition formulas; with repetition allowed, r may be larger than n.
