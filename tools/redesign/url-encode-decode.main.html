Which characters get percent-encoded

Percent-encoding writes a character as % followed by the hexadecimal value of each of its UTF-8 bytes. encodeURI() keeps characters that structure a URL. encodeURIComponent() encodes them, which is what you want for a single query value.

How the numbers are worked out.

Percent-encoding

Each byte of the character's UTF-8 form becomes a percent sign and two hexadecimal digits.

%C2%B3 = ³ (two UTF-8 bytes)
space = %20

Component or full URL

Encode a single value with the component option. Encode a whole address with the full URL option so : / ? & = # stay as they are.

encodeURIComponent(value)
encodeURI(url)

Decoding

Each %XX sequence is turned back into its byte, and bytes are read as UTF-8.

Frequently asked questions

What is the difference between encodeURI and encodeURIComponent?expand_more

encodeURI keeps characters such as : / ? & = # so a whole address still works. encodeURIComponent encodes them, so use it for a single value inside a URL.

When should a space be %20 and when +?expand_more

%20 is correct everywhere in a URL. A + means a space only in HTML form data (application/x-www-form-urlencoded), such as query strings from forms.

Why does ³ become %C2%B3?expand_more

Non-ASCII characters are first turned into UTF-8 bytes, and each byte is written in hex. ³ is the two bytes C2 and B3.

Why does decoding fail with a malformed error?expand_more

A % must be followed by two hexadecimal digits, and the bytes must form valid UTF-8. A stray % or truncated sequence causes this.
