Comment fonctionne le moteur de calcul

La partie entière se convertit par divisions successives ; la partie fractionnaire, par multiplications successives — le tout avec des fractions BigInt exactes, et non en virgule flottante, afin que les longues suites de chiffres restent exactes.

    0xDEADBEEF = 3,735,928,559

    Partie fractionnaire

    Convertir 42.625 en binaire.

    42 = 101010₂ ; 0.625 × 2 de façon répétée donne .101₂
    42.625 = 101010.101₂

    Comment fonctionne la conversion de base

    • Partie entière, toute base → décimal : multipliez chaque chiffre par sa valeur de position (baseᵏ) et additionnez.
    • Décimal → toute base : divisez de façon répétée par la base d'arrivée ; les restes, lus du dernier au premier, sont les chiffres.
    • Partie fractionnaire → toute base : multipliez de façon répétée la fraction par la base d'arrivée ; la partie entière obtenue à chaque fois est le chiffre suivant.

    Questions fréquentes

    Pourquoi certaines fractions ne se terminent-elles jamais dans une autre base ?expand_more

    Une fraction se termine en base b exactement lorsque les seuls facteurs premiers de son dénominateur réduit sont aussi des facteurs premiers de b. 0.1 (1/10) se termine en décimal mais se répète indéfiniment en binaire, car 5 n’est pas un facteur de 2 — pour la même raison que 1/3 se répète en décimal.

    Quels chiffres utilise une base supérieure à 10 ?expand_more

    Après 9, les lettres prolongent la séquence : A=10, B=11, … jusqu’à Z=35, ce qui permet des bases allant jusqu’à 36. L’hexadécimal (base 16) utilise 0–9 et A–F.

    Pourquoi la base 16 est-elle si courante en informatique ?expand_more

    Chaque chiffre hexadécimal représente exactement 4 bits, de sorte qu’un octet s’écrit toujours avec exactement 2 chiffres hexadécimaux — une façon bien plus compacte et lisible d’écrire des données binaires, utilisée pour les adresses mémoire, les codes couleur, etc.

    Quelle taille de nombre cet outil peut-il gérer ?expand_more

    La partie entière accepte un nombre arbitraire de chiffres (arithmétique BigInt exacte) ; la partie fractionnaire est calculée sur 20 chiffres dans la base cible, avec indication lorsque le développement est tronqué plutôt qu’exact.

    Quelle est la différence entre octal et hexadécimal ?expand_more

    Ce sont deux abréviations du binaire : l’octal (base 8) regroupe les bits par 3, l’hexadécimal (base 16) par 4. L’hexadécimal est plus courant aujourd’hui car il s’aligne sur les octets de 8 bits ; l’octal reste utilisé pour les permissions de fichiers Unix.
