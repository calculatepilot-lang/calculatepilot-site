Calculatrice de durée entre dates et de jours ouvrés

Comptez les jours entre deux dates, ajoutez ou soustrayez des jours à une date, ou comptez uniquement les jours ouvrés. Excluez les week-ends, les jours fériés des États-Unis, du Royaume-Uni, du Canada ou d'Australie, ainsi que vos propres dates, et obtenez les semaines, les mois et le prochain jour ouvré.

Comment fonctionnent les décomptes

Jours calendaires

jours = (fin − début) ÷ 86,400,000 ms (+1 si le jour de fin est inclus)

Jours ouvrés

compter chaque date d dans [début, fin) où d n'est ni un week-end, ni un jour férié, ni un jour de congé supplémentaire

Année bissextile

(a mod 4 = 0 et a mod 100 ≠ 0) ou a mod 400 = 0
Jours fériés

Ce qui est exclu

Les jours fériés fédéraux américains sont les onze définis par 5 U.S.C. 6103. Un jour férié tombant un samedi est observé le vendredi, et un jour férié tombant un dimanche est observé le lundi. Les listes du Royaume-Uni, du Canada et d'Australie couvrent les jours fériés nationaux courants, et les règles mobiles comme Pâques sont calculées.

Les jours fériés régionaux et ponctuels ne sont pas inclus. Ajoutez-les dans la zone des jours de congé supplémentaires.

Comment compter les jours entre deux dates

  • Choisissez les dates de début et de fin et décidez si le jour de fin est compté.
  • Pour les jours calendaires, soustrayez les dates. Les jours bissextiles sont gérés automatiquement.
  • Pour les jours ouvrés, retirez les week-ends et les jours fériés qui tombent en semaine.
  • Pour trouver une échéance, utilisez Ajouter ou soustraire des jours avec l'option des jours ouvrés.

Les contrats et les lois définissent la manière de compter les jours. Vérifiez si le premier ou le dernier jour est inclus, et quels jours fériés s'appliquent, avant de vous fier à une date.

Questions fréquentes

Le jour de fin est-il inclus dans le décompte ?expand_more

Par défaut, non : le décompte va de la date de début jusqu'à la date de fin, celle-ci non comprise. Activez Inclure le jour de fin pour ajouter un jour. Les délais légaux précisent souvent la règle, vérifiez donc la vôtre.

Comment les jours ouvrés sont-ils comptés ?expand_more

Toute date de la période qui n'est ni un samedi, ni un dimanche, ni un jour férié choisi, ni un jour de congé supplémentaire compte comme un jour ouvré. Un jour férié qui tombe un week-end n'est pas déduit deux fois.

Quels jours fériés américains sont exclus ?expand_more

Les onze jours fériés fédéraux : New Year's Day, Martin Luther King Jr. Day, Washington's Birthday, Memorial Day, Juneteenth, Independence Day, Labor Day, Columbus Day, Veterans Day, Thanksgiving et Christmas Day, avec les règles de report lorsqu'ils tombent un week-end.

Comment l'outil gère-t-il les années bissextiles ?expand_more

Les dates sont comptées selon le véritable calendrier grégorien ; le 29 février est donc inclus les années bissextiles. Une année est bissextile si elle est divisible par 4, sauf les années séculaires non divisibles par 400.

Pourquoi le prochain jour ouvré est-il utile ?expand_more

Il indique quand le travail reprend après la fin de la période, en excluant les week-ends et les jours fériés. C'est pratique pour les délais de livraison, les préavis et les passations de projet.
